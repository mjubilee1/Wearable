# Before production

Known work that has to land before a public launch. None of it is urgent while the phone app is still a dev build.

## Phone notifications

When someone replies, the message stays in Nearby. A closed app should get a phone notification, the same way WhatsApp does.

Holding this until the app is on the App Store and the push certificates are in place. The app does not register for push today. An open thread already refreshes every few seconds, so a reply still shows up while Nearby is open.
